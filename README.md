# Personal Portfolio Website

A full-stack personal portfolio website built using the MERN Stack.

## Tech Stack

### Frontend
- React.js
- CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

---

# Features

- Responsive Portfolio Website
- About Section
- Skills Section
- Projects Section
- MongoDB Database Integration
- Express Backend API
- React Frontend
- Fully Responsive Design

# Installation

## Clone Repository

```bash
git clone https://github.com/KesaramVedaShruthi/portfolio.git
```

---

# Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

# Backend Setup

```bash
cd backend
npm install
npx nodemon server.js
```

---

# MongoDB Setup

Create `.env` inside backend folder:

```env
MONGO_URL=your_mongodb_connection_string
```

---

# Run Project

## Frontend

```bash
npm run dev
```

Runs on:

```txt
http://localhost:5173
```

---

## Backend

```bash
npx nodemon server.js
```

Runs on:

```txt
http://localhost:5000
```
